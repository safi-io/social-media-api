## Overview

**social-media-API** is a full-featured backend system designed for social media and project portfolio management.  
It allows users to create profiles, connect with friends, follow others, post updates, and showcase projects effortlessly.  

A key feature is the **automatic generation of HTML/CSS/JS portfolio pages** from project descriptions using LLMs, so users can instantly have a live portfolio page without manually building a website.  

This project is built with **FastAPI**, uses **PostgreSQL** for persistent storage, and is **Docker containerized** for scalable deployment.  

---

## Main Features

- **User Profiles and Authentication** – Secure registration, login, and profile management.  
- **Friendship and Following System** – Add friends, follow other users, and explore content from your network.  
- **Project Showcasing** – Upload projects and generate live HTML/CSS/JS portfolio pages automatically.  
- **Post Creation and Discovery** – Share posts, search for content, and explore updates from other users.  
- **HTML Page Generation via LLM** – Automatically generate fully functional webpages from project descriptions.  
- **Dockerized Deployment** – Containerized backend for easy deployment and scalability.  
- **Database Migrations with Alembic** – Efficient management of PostgreSQL schema changes.  
- **VPS Deployment Ready** – Fully compatible with self-hosted VPS environments.  

---

## Technology Stack

- **Backend Framework:** FastAPI  
- **Database:** PostgreSQL with Alembic migrations  
- **Containerization:** Docker  
- **Frontend Hosting:** Frontend deployed separately (e.g., Netlify)  
- **AI/LLM Integration:** Automatic HTML/CSS/JS page generation from project descriptions  
- **Deployment:** Self-hosted VPS, fully containerized  

---

## Usage

Once the backend is running:

- Register a user and create a profile.  
- Add friends, follow other users, and view their posts.  
- Upload a project and generate a live portfolio webpage automatically.  
- Create and view posts, search for projects, and explore content from other users.  
- Interact with the API via Swagger UI for testing and development.  

---

## Deployment

- Fully containerized using Docker for VPS deployment.  
- Frontend hosted separately (e.g., Netlify) and connected via API endpoints.  
- LLM-powered HTML page generation enables dynamic project showcases for uploaded projects.
